# Eventia - Interfaz HTML y CSS

## Cómo abrirlo
1. Descomprimí la carpeta `eventia_frontend`.
2. Abrí `publico/index.html` en el navegador.
3. Los estilos compartidos están en `css/estilos.css`.

## Importante
- Es una maqueta de frontend: los formularios todavía no guardan datos.
- Los enlaces de navegación son demostrativos y se pueden adaptar.
- Los datos de las tablas son ejemplos; reemplazalos por consultas PHP/MySQL.
- La validación de permisos por rol y sucursal debe realizarse en el backend, nunca solamente ocultando enlaces.
- El flujo de invitación necesita generar un token seguro, guardarlo con vencimiento y enviar el enlace desde PHP.
